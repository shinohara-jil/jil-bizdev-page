## カテゴリ全体の傾向

1. **「戦略だけで終わらない」が全社共通の軸**。「戦略立案から施策実行まで一気通貫」（才流）、「実行なき戦略は、もういらない」（SALES ROBOTICS）、「戦略に留まらない。」（Zingth）など、コンサル（考えるだけ）と代行（手を動かすだけ）の**"間を埋める"ポジション**を取りに行く言い方が定番になっている。
2. **悩みは「属人化」「再現性がない」「戦略が現場に落ちない」に集中**。悩みを箇条書きで並べ、「仕組み化」「型」「再現性」で解決する流れが王道になっている。
3. **入口を「課題」や「フェーズ」から選ばせる設計が増えている**（プロセルトラクション「どのフェーズからでも、支援を開始できる」、Acrosstudio Phase1〜4、SALES ROBOTICS「解決したい課題から探す」）。
4. **実績は「社数・件数」の大きな数字＋大手の社名事例**が基本。小規模な会社は、数字の代わりに**事例ごとのBefore/After（MRR4.8倍など）と「体制・費用」**を見せて具体性で勝負している（Zingth、AccelSales）。
5. **小規模ブティックほど「人」を前面に出す**。Zingthは全メンバーの経歴を掲載し、「最大の強みは"人"」と書く。大手は人ではなく「メソッド・認定資格・データ」で品質を保証する。
6. **料金はほぼ非公開**（「お問い合わせください」）。例外としてZingthは事例ごとに「2名×週2日常駐／月額400万円〜」と公開しており、目立つ。期間は「最低3か月」「最短2週間で開始」など**始めやすさ**を示す会社が多い。
7. **AIの打ち出しは「人×AI」**。AIで置き換えるのではなく、「人が顧客に向き合う時間を増やす」（SALES ROBOTICS、BALES）という言い方が主流。AI専業のAcrosstudioは「構想と実装を、ひとつのチームで」「PoC止まりにしません」で差別化している。

- **CTA**：「お問い合わせ・ご相談」（「具体的な相談内容がまとまっていなくても構いません。」と心理的ハードルを下げる一文つき）。ほかに「無料転職相談」
- **デザインのトーン**（文面からの印象）：経営者向けの硬めで断定的なトーン。短い言い切りの見出し
- **JILが真似できそうな点**
  - 「戦略はあるのに実行されない」など**"間"を埋める**という言い方は、JILの「設計だけでなく実行まで」とほぼ同じ価値。そのまま参考になる
  - **事例ごとに「何人×週何日×月額いくら〜」を出す**のは、小さい会社ほど効く（発注の検討が一気に具体的になる）
  - 他タイプとの比較表（コンサル／代行／AIベンダー／制作会社 vs JIL）
  - メンバー全員の経歴を出して「人が強み」と言い切る

  - **CTAを「資料DL／15〜30分の相談／問い合わせ」の3段階に分け、所要時間や返信の早さを書く**→ 問い合わせのハードルが下がる
  - 「〜ではありません」で既存の業者イメージを否定する書き出し（JILなら「単なるコンサルではありません」）
  - 「人×AI」の言い方
- **JILには合わない点**：IS代行が中心で、経営・プロダクト開発の話は無い

## JILへの示唆（まとめ）

| 学べる要素 | 参考企業 | JILでの使い方の例 |
|---|---|---|
| 「戦略と実行の"間"を埋める」宣言 | Zingth、SALES ROBOTICS、才流 | FVで「設計で終わらせない。実行まで、同じチームで。」系の言い切り |
| 悩みをフェーズ順に並べる／フェーズで入口を選ばせる | プロセルトラクション、Acrosstudio | 0→1／1→10／10→100それぞれの悩みを並べ、該当フェーズのメニューへ誘導 |
| 「日々の関わり方」「○か月プログラム例」 | TimeSkip | 伴走の中身（定例・チャット・現場同席・資料作成）を具体化 |
| 工程ごとの「実施内容／成果物」 | SALES ROBOTICS | 業務フロー設計・営業設計で何が納品されるかを見える化 |
| 事例に「体制（人数×稼働）＋月額〜」 | Zingth | 実績が少なくても具体性で信頼を作れる |
| 他タイプとの比較表 | Zingth、AlphaDrive | コンサル／代行／AIベンダー／制作会社 と JIL の比較 |
| 「構想と実装を一つのチームで」 | Acrosstudio | コンサル/PM＋AIエンジニア＋デザイナーが同じチームと言える |
| 人を前面に（経歴＋専門タグ） | Zingth、AlphaDrive | 少人数だからこそ全員の顔と経歴を出す |
| 段階的なCTA | BALES、TimeSkip | 「15分の壁打ち相談」「資料DL」「料金について知りたい」 |
